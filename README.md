# 🔐 PasswordManager

PasswordManager è un'applicazione progettata per **gestire e memorizzare in modo sicuro le password** degli utenti.  
Il progetto permette di organizzare credenziali di accesso a diversi servizi in modo semplice e centralizzato.

## 📌 Obiettivi del progetto

- Gestire password in modo sicuro
- Centralizzare le credenziali degli utenti
- Ridurre il rischio di perdita o riutilizzo delle password
- Fornire un progetto semplice per studiare o dimostrare i principi di un password manager

## ✨ Funzionalità

- ➕ Aggiunta di nuove credenziali
- 📄 Visualizzazione delle password salvate
- ✏️ Modifica delle credenziali
- ❌ Eliminazione delle password
- 🔐 Gestione sicura dei dati

## 🚀 Installazione

Clona il repository:

```bash

````

Entra nella cartella del progetto:

```bash
cd PasswordManager
```

Esegui lo script main.py

```python
python main.py
```

## ▶️ Utilizzo

1. Avvia l'applicazione
2. Inserisci o crea le credenziali da salvare
3. Gestisci le password tramite le funzionalità disponibili

## 🔒 Sicurezza

Quando si sviluppa o utilizza un password manager è importante:

* non salvare password in chiaro
* utilizzare hashing o crittografia
* proteggere l'accesso tramite password principale
* non condividere file contenenti credenziali
